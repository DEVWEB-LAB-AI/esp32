Complete Ngrok Setup Guide

📋 Step-by-Step Ngrok Setup

1 Create Ngrok Account (FREE)
Go to ngrok.com → Sign up for free account
⚠️ Save your login credentials! You'll need them later.
2 Get Your Authtoken
After signing up, go to:
https://dashboard.ngrok.com/get-started/your-authtoken
📋 Click "Copy" button to copy your authtoken
Your authtoken looks like:
2Ab3Cd4Ef5Gh6Ij7Kl8Mn9Op0Qr1St2Uv
3 Install Ngrok on Your Computer
# Windows:
Download from ngrok.com → Extract → Run ngrok.exe # Mac:
brew install ngrok # Linux:
sudo snap install ngrok
4 Authenticate Ngrok
# Open Terminal/Command Prompt
ngrok config add-authtoken YOUR_TOKEN_HERE
✅ You only need to do this once per computer
5 Start Ngrok Tunnel
# Make sure ESP32-CAM is running on port 80
# Then run:
ngrok http 80
🔄 Keep this terminal window open while using ngrok
6 Copy Ngrok URL
After running ngrok, you'll see:
Forwarding https://abc-123-456.ngrok.io -> http://localhost:80
📝 Copy the URL: abc-123-456.ngrok.io
7 Use in This App
1. Paste ngrok URL in "Camera IP Address" field
2. Set Connection Method to "Cloud"
3. Click "Connect to Camera"
⚠️ Important Notes:
  • Free ngrok: URL changes every time you restart
  • Session expires after 2-8 hours
  • For permanent URL, upgrade to paid plan
  • Keep ngrok running in background
💡 Pro Tips:
  • Save successful ngrok URLs in "Saved Cameras"
  • Use "Auto-detect" button if ngrok is running locally
  • Share the ngrok URL with friends/family
  • Test with "Test Connection" button first
